# Module 5 — Locator candidate generation

Module 5 adds deterministic locator extraction and live uniqueness checks for every crawled element.
It introduces the `selector locators` command, versioned locator-report schema, Playwright code
serialization, frame-aware evaluation, redaction-aware omission, and CSS/XPath escaping helpers.

This module deliberately does not assign final stability scores. Module 6 owns scoring, penalties,
and confidence ranking.
