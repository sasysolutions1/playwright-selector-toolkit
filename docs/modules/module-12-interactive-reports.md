# Module 12 — Interactive report dashboard

## Delivered

- offline search and filtering;
- dynamic facet controls;
- issue-only mode;
- clickable metric drill-down;
- sortable tables;
- collapsible sections;
- source toggles;
- live visible-row summaries;
- theme cycling;
- visible-row CSV export;
- filtered printing;
- screenshot lightbox;
- static no-script report mode;
- browser regression tests.

## Compatibility

The generated dashboard uses standard browser APIs and requires no server. The static `--no-interactive` mode is available for environments with strict inline-script policies.
